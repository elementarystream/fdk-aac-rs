# fdk-aac-rs-tpenc

Transport encoder: raw, ADIF, ADTS, LATM/LOAS (port of libMpegTPEnc).

This is an internal crate of [fdk-aac-rs](https://github.com/elementarystream/fdk-aac-rs). It is
not a public API and may change in any release; use the
[`fdk-aac-rs`](https://crates.io/crates/fdk-aac-rs) crate instead.

It is part of a Third-Party Modified Version of the Fraunhofer FDK AAC Codec Library for Android.
The changes are described in the repository's README; the license is in `LICENSE.txt`.
